01 · Architecture

The laptop prepares, the board performs

A Rust toolkit on the laptop converts, tests and tunes the models. The board only runs them. Both use the same library, so both compute the very same numbers.

On the laptop
facekit
1Import the two published models
2Shrink the detector to small whole numbers
3Test on 6,000 photo pairs of 5,749 people
4Tune the limits: 24,271 test attempts, 22,920 of them by strangers
5Collect 200 stranger faces for comparison
Shared Rust library
crates/vision
Image processing, both networks, the gallery and the decision
On the board
face_id firmware
Camera and live preview on the screen
Network 1: the detector (YuNet)
Network 2: the recognizer (MFN_S8_V1)
The decision: known person or stranger?
Up to 4 people: six face descriptions each, saved in flash, so they survive restarts and new firmware
Tested on both machines: at every start the board runs both networks on test inputs and compares the result with the laptop’s. It matches bit for bit.
