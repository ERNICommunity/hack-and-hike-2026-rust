01 · Architecture

Two cores, three kinds of memory

One core runs face identification, the other keeps touch, sensors, sound and USB alive. Every piece of data lives in the fastest memory it fits into.

ESP32-S3 chip
2 cores · 240 MHz
CPU0
Runs face identification
Main loop
find → check → cut out → describe → decide, again and again
Stream task
pauses the main loop briefly every 2 ms to collect the camera’s pixels, and draws the live preview
CPU1
Keeps the rest alive
Touch screen
Motion and light sensors
Microphone, speaker
Radio (unused by this app)
USB log to the laptop
Internal RAM
512 KB, 144 KB free for data
fastest: a few clock ticks per read
What lives here
The recognizer’s work in bands: seven rows of a block’s widest values at a time (69 KB), so they never go out to the slower PSRAM chip
PSRAM
extra chip · 8 MB · 40 MB/s
medium
What lives here
The networks’ learned numbers (1.35 MB), their working memory (0.8 MB) and the camera images
Flash
4 MB · 10 MB/s
slow, but keeps data without power
What lives here
The firmware with both models built in, and the enrolled faces (128 KB)
